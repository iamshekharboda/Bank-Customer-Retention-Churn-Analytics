# 🏦 Bank Customer Retention & Churn Analytics

An end-to-end data analytics project analyzing customer churn across 10,000 banking records. This project demonstrates a full-stack data pipeline—from raw data cleaning and winsorization using **Python**, structured data modeling and aggregation with **SQL**, to an executive-ready interactive dashboard built in **Microsoft Power BI**.

---

## 📌 Project Overview

Customer churn is a critical metric for retail banking. This project identifies key demographic, financial, and behavioral factors influencing customer attrition, providing actionable insights to improve retention strategies.

### 🔑 Key Performance Indicators (KPIs)
* **Total Customers:** 10,000
* **Total Exited (Churned):** 2,038
* **Overall Churn Rate:** 20.4%
* **Retained Customers:** 7,962
* **Average Account Balance:** ₹76.37K
* **Average Credit Score:** 650.8
